Smart Inspect: Municipal Inspection System

CPIT-251 Software Engineering & CPIT-305 Advanced Programming · Team leader · Java

  • Java
  • Swing
  • Sockets
  • Multithreading
  • MySQL / JDBC
  • File I/O
  • JUnit

Smart Inspect helps Jeddah Municipality inspectors check seaside establishments in the field. An inspector logs in, looks up an establishment by its license number, records an inspection with a violation, and can review that establishment's full inspection history.

This one project was developed for two courses, and I led the team in both. In CPIT-251 (Software Engineering) it was the Seashore Violation Tracking App, built with XP agile practices. In CPIT-305 (Advanced Programming) it grew into a full client-server system with a GUI, threads, networking and a database.

What it does

  • Login: inspectors sign in with name, ID and password, checked against the database.
  • Search: look up an establishment by license number and see its details.
  • Inspect: write the result of an inspection and choose the violation from a drop-down list.
  • History: view every past inspection for an establishment: date, inspector, notes and violation.
  • Statistics: total inspections, the most common violation and this month's inspection count.

How it works

  • Client and server: the Swing client connects to a server over a socket. They talk through a small text protocol with commands such as LOGIN, SEARCH, INSPECT and HISTORY.
  • Threads: the server gives every connected inspector their own thread, so several inspectors can work at the same time. A separate background thread checks every 24 hours for establishments whose license has expired.
  • Database: inspectors, establishments, violations and inspection history live in MySQL, accessed through JDBC with PreparedStatement.
  • File I/O: the server writes timestamped entries to a log file for startup, logins and expired licenses.
  • Structure: the logic classes (Establishment, Inspector, License, Violation and others) are kept separate from the GUI frames (login, main menu, search, inspection form, history and statistics).
